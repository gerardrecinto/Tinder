# Tinder Swipe UI

![Swift](https://img.shields.io/badge/Swift-3%2B-F05138?logo=swift&logoColor=white)
![iOS 9+](https://img.shields.io/badge/iOS-9%2B-000000?logo=apple&logoColor=white)
![UIKit](https://img.shields.io/badge/UIKit-Gestures-blue)

![Demo](docs/assets/demo2.gif)

Tinder-style card swipe UI built with Swift and UIKit. Custom pan gesture recognizer drives card rotation and animated transitions for swipe-left / swipe-right with spring snap-back.

## Tech

| Layer | Tech |
|---|---|
| Language | Swift |
| UI | UIKit, UIPanGestureRecognizer |
| Animation | UIView spring animations |
| Layout | Auto Layout |

## Setup

```bash
git clone https://github.com/gerardrecinto/tinder-swipe-ui.git
open tinder-swipe-ui/Tinder.xcodeproj
```

Build and run on the iOS Simulator (Xcode 8+).
